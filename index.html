发布内容

完整目录运行

下载 zip 后解压整个文件夹运行 gui.exe。不要只复制单个 exe，程序还需要随包资源和 ADB。

授权校验

程序启动前会进行授权和完整性检查。未激活、过期或运行环境异常时不会进入主工作台。

安全边界

公开仓库只放发布包和更新清单。源码、Cloudflare Worker、Admin Token 和账号数据不进入此仓库。

安装步骤

1

从 GitHub Release 下载最新版 6D-v*-windows-x64.zip。

2

解压到固定目录，例如桌面或工作盘目录，保持文件夹结构完整。

3

运行 gui.exe，根据授权页输入激活码完成绑定。

4

如遇更新提示，返回本页下载新版覆盖到新目录后运行。

更新说明

客户端通过 latest.json 读取最新版本。正式包发布前，本页不会写入可触发更新的清单，避免用户下载到未验收版本。
