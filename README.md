# 6D Release Public

本仓库提供 6D 桌面工作台的公开下载页、`latest.json` 更新清单和 GitHub Releases 下载入口。

公开主页：https://gufeng443.github.io/6D-release/

当前稳定版：`v0.6.3`。本版本新增全参账号 TXT/JSON 转标准 6 段协议号，转换文件自动命名为 `原文件名_6段_数量N.txt`，并会跳过缺少 client static key 的不完整记录后继续转换其余账号。

## 首次使用 / 新电脑

- 支持 Windows 10 / 11 x64。
- 下载发布 ZIP 后，先将整个压缩包完整解压到独立文件夹。
- 不要直接在 ZIP 内运行，也不要只复制单个 `6D.exe`。
- 打开受支持的安卓模拟器，并在模拟器设置中开启 Root 权限。
- 使用个人版时确认已安装 WhatsApp；使用商业版时确认已安装 WhatsApp Business，并在 6D 中选择正确类型。
- 激活时需要互联网连接。
- 发布包已包含所需的 Python、ADB 和运行组件，无需另外安装或配置 Python、ADB。

进入工作台后，点击“刷新设备”并确认目标设备出现在列表中，再执行后续操作。

## 激活后按钮没有反应

按以下顺序排查：

1. 点击“刷新设备”。
2. 确认目标模拟器已启动并出现在设备列表中。
3. 确认模拟器已开启 Root 权限。
4. 确认 6D 中选择了正确的个人版或商业版类型。
5. 确认模拟器内已安装对应的 WhatsApp 或 WhatsApp Business 包。
6. 关闭并重新启动 6D。

排查过程不需要提供账号密码、密钥或其他私密资料。

## 下载与校验

主页优先读取根目录 `latest.json`，展示当前版本、文件大小、发布日期和 SHA-256，并将主下载按钮指向当前发布包。读取失败时，下载按钮回退到 GitHub Releases 最新页。

本仓库不包含主程序源码、服务端或后台管理代码、激活信息、用户账号数据、日志、导出包或测试样本。
激活码后台、后台管理 UI、Cloudflare/Worker 配置、Token、`.env*` 和本地授权数据只保留在私有环境，不进入公开仓库或公开发布附件。
